# Console Based Job Portal using Core Java

## Project Description
A console-based Job Portal application developed using Core Java by following Object-Oriented Programming (OOP) principles.

## Features
- User Registration
- User Login
- View Profile
- Apply for Job
- Change Password
- Logout

## OOP Concepts Used
- Class
- Object
- Constructor
- Encapsulation
- Getter and Setter Methods

## Core Java Concepts Used
- Variables
- Data Types
- Scanner Class
- if-else
- Nested if
- switch
- while loop
- Methods
- String methods
